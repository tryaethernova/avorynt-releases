# AVORYNT 0.0.01 – Public Beta

Der erste offizielle **Windows-Beta-Release von AVORYNT** ist da.

AVORYNT wird unter **TryAetherNova** entwickelt und befindet sich aktuell in einer frühen öffentlichen Testphase. Mit Version **0.0.01** beginnt der erste offizielle Release-Zyklus für Tester.

## 🚀 Enthalten

* **AVORYNT Browser für Windows x64**
* Installationspaket für die Beta-Version
* **SHA-256-Prüfsumme** zur Überprüfung des Installers
* Sauberes Release-Paket ohne persönliche Browserdaten oder lokale Benutzerprofile

## 🧪 Beta-Status

Diese Version ist ausdrücklich als **Beta-Testversion** vorgesehen.

Einzelne Funktionen können sich noch verändern, erweitert werden oder in bestimmten Situationen noch nicht wie vorgesehen funktionieren. Feedback zu Fehlern, Bedienung, Stabilität und Verhalten des Browsers ist daher ausdrücklich willkommen.

## 🔒 Datenschutz beim Release

Persönliche Browserprofile, Verlauf, Cookies, gespeicherte Sitzungen, Zugangsdaten oder andere lokale Benutzerdaten sind **nicht Bestandteil des veröffentlichten Release-Pakets**.

## 📦 Veröffentlichung

Der Release wird über den **TryAetherNova Release Manager** vorbereitet.

Vor einer öffentlichen Veröffentlichung werden Installer, Versionsdaten und Release-Dateien nochmals separat geprüft und bestätigt.

---

**Version:** 0.0.01
**Status:** Public Beta
**Plattform:** Windows x64
**Projekt:** AVORYNT
**Publisher:** TryAetherNova

Vielen Dank an alle, die AVORYNT bereits in dieser frühen Phase testen und bei der Weiterentwicklung unterstützen.
